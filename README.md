## Week 2 Project Description: Python and Pandas

The main objective of this project is to learn data manipulation and analysis using Python and the Pandas library. This project focuses on filtering, grouping, sorting, and merging datasets to extract meaningful information from structured data.

In this project, a sample student dataset is created using Pandas DataFrame. The dataset contains student IDs, names, departments, cities, attendance percentages, marks, and fee payment status. A total of 20 practical exercises are performed to understand different Pandas operations.

The exercises include displaying the first and last rows, checking dataset dimensions, selecting specific columns, filtering records based on conditions, sorting values, and checking data types. The project also uses the `groupby()` function to calculate the number of students, average marks, average attendance, and highest marks for each department.

Additionally, the `apply()` function is used to create a Pass or Fail result column based on student marks. The `merge()` function is used to combine student information with department mentor details and fee information.

Through this project, I gain practical experience in data handling, data summarisation, and combining information from multiple tables.
